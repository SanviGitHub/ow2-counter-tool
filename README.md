# Overwatch Counter Tool — 2026 Edition

Una herramienta táctica minimalista de alta precisión para **Overwatch (2026)**, diseñada para consultar counters directos, sinergias, subroles oficiales y construir composiciones 5v5 óptimas en tiempo real.

### Características Principales
1. **Agentes & Counters (`index.html`)**
   - Cuadrícula táctica dividida en **Tank / Damage / Support** con indicadores de Tier competitivo (`S / A / B`) y badge `26` para los nuevos agentes.
   - Buscador instantáneo (atajo `/`) y filtros rápidos por arquetipo (`Dive`, `Brawl`, `Poke`, `Nuevos 2025–26`, `Tier S`).
   - Dossier táctico lateral interactivo: muestra retrato, rol, subrol oficial 2026 (`Initiator`, `Stalwart`, `Bruiser`, `Flanker`, `Sharpshooter`, `Specialist`, `Recon`, `Tactician`, `Medic`, `Survivor`), dificultad, consejo estratégico 2026, **Fuerte contra**, **Counters directos** y **Mejores sinergias** (clicables para navegar entre agentes).
2. **Team Builder 5v5 (`team.html`)**
   - Selector visual 5v5 con vista previa de retratos en vivo y presets competitivos 2026 (`Meta Dive 26`, `Meta Brawl 26`, `Meta Poke 26`).
   - Medidor en tiempo real del arquetipo rival (`Brawl / Dive / Poke`).
   - Algoritmo híbrido de recomendación 5v5 que pondera el counter del Tanque rival y puntúa dinámicamente los matchups contra los 5 integrantes enemigos, explicando por qué se sugiere cada héroe.
